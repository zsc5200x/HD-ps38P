# 旧跟单引擎参考源码

`follower/` 内的 17 个 Python 文件来自旧系统，仅用于理解盘口解析、任务调度、分单及结果处理逻辑。本项目实际运行的跟单实现位于 `ps38app/follow/`，不会导入此目录。

这份参考代码依赖旧系统的 `hdzz.*`、`member_arsenal_watch` 等模块，不能在当前仓库中独立运行。需要复用逻辑时，应按本项目的账号池、SQLite 存储、配置和服务生命周期重新适配，并使用本地模拟测试验证。

本地原始压缩包 `follower-engine.zip` 包含同一组 17 个源码文件，没有额外运行资源；入库源码仅清理了行末空白和文件末尾多余空行，业务逻辑与原包一致。源码已单独保存，重复 ZIP 无需提交到 Git。
